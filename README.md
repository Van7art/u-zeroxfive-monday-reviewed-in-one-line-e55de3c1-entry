Monday, Reviewed in One Line: **Monday reviewed: one star — the meeting could have been an email, the email could have been silence, and I could have been asleep.**

Monday, reviewed in one line: one star — the meeting could have been an email, the email could have been silence, and I could have been asleep. A real review shape with concrete Monday details and an escalating punchline. The other candidates — the alarm/coffee/inbox list and the 3 a.m. software update — are kept in `vA/`, `vB/`, `vC/`; vA was chosen because it is the most repeatable and the most concrete.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 26.13.1 per the kit).
The program writes exactly the entry above to `/output/entry.txt` — no
trailing newline, so the file holds exactly the entry — and prints exactly
that text to stdout. It uses no network, no randomness, no clock and no
environment input, so two runs produce byte-identical output.
